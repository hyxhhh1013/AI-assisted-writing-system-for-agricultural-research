# 产品需求文档 (PRD) - 农业科研 AI 辅助写作系统

## 1. 文档概述
本文档旨在定义“农业碳基肥与盐碱地改良科研 AI 辅助系统”的核心功能与业务逻辑，确保研发团队与业务方目标对齐。

## 2. 目标与价值 (Dean's Perspective)
*   **核心目标**：构建实验室专属 AI 写作工具，解决通用模型在农业垂直领域（水稻/烟草/碳基肥/盐碱地）的“术语配错”和“逻辑生硬”问题。
*   **商业价值**：通过 RAG 技术沉淀实验室资产，将论文初稿产出效率提升 50% 以上，降低对外部昂贵且低质工具的依赖。

## 3. 核心功能点 (Core Features)

### 3.1 专属农业知识库 (RAG Engine)
*   **文献上传与管理**：支持 PDF/Word/TXT 格式批量上传。
*   **智能切片与索引**：针对农学论文结构（摘要、方法、结果等）进行深度解析。
*   **垂直检索**：在生成内容前，强制检索实验室私有库，确保术语符合农学规范。

### 3.2 结构化分步写作流水线 (Writing Pipeline)
*   **Step 1: 实验数据分析**：输入 Excel/CSV 指标，AI 自动提取核心变化趋势与显著性差异。
*   **Step 2: 论文提纲生成**：根据研究方向，生成符合 SCI 或核心期刊标准的逻辑大纲。
*   **Step 3: 模块化扩写**：
    *   **摘要生成**：基于核心数据快速提炼。
    *   **前言构建**：按照“大背景 -> 小背景 -> 科学问题 -> 本研究目的”的逻辑链条生成。
    *   **材料与方法**：标准化描述实验设计。
    *   **结果与讨论**：结合 RAG 检索结果进行深度对比讨论。

### 3.3 数据隔离与安全
*   **内网访问控制**：系统部署于实验室局域网，限制外部访问。
*   **脱敏传输**：所有发送至云端 API 的数据需经过关键词脱敏。

## 4. 非功能性需求
*   **易用性**：针对非计算机专业人员设计，采用极简表单式交互。
*   **稳定性**：支持至少 20 人同时在线并发请求，具备 API 熔断保护。
*   **可扩展性**：支持未来接入更多垂直领域（如：果树、植保等）的知识库。
