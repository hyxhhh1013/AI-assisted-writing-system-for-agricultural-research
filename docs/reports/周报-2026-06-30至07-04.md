## 一、本周核心工作（6.30 — 7.4）

### 1.1 Direction 模块 — 8 维度分析框架

- 定义 8 维度评分模型：研究空白、方法可行性、数据可获得性、创新性、发表潜力、资源需求、时间线、风险评估
- 实现 `contracts/direction.ts` 类型系统 + `services/direction-service.ts` CRUD
- 前端 `DirectionWorkspace` 主组件：概览/分析/路线图/基金申请四 Tab 工作台
- 分析面板 `AnalysisPanel`：8 卡网格 + Slider 评分 + 置信度标签
- 维度配置面板：自定义启用/禁用维度、权重调节

### 1.2 Socratic Mentor 预承诺问答

- 自然语言 Q&A 替代传统技术字段填写（`SocraticMentor` 组件）
- 渐进式问答流程：研究方向 → 核心假设 → 预期贡献 → 风险评估 → 资源盘点
- confirmed state 锁定答案，防止误改
- Q&A 答案自动填充 8 维度分析上下文
- 修复跨 Tab 切换时分析维度状态丢失

### 1.3 分析报告可视化

- Recharts 雷达图：8 维度评分概览，支持与已发表论文对标曲线叠加
- 柱状图：各维度置信度分布
- 导出分析报告摘要（PNG/Markdown）

### 1.4 双角色架构

- PI 视角：宏观战略视图（资源分配、可行性、发表策略）
- Researcher 视角：微观执行视图（方法细节、实验设计、数据收集）
- 角色切换保留各自分析状态与笔记
- 视角差异高亮（评分分歧 > 20% 标红）

### 1.5 路线图与规划工具

| 功能 | 说明 |
|------|------|
| **Gantt 图** | 研究时间线可视化，支持阶段拖拽、依赖连线、里程碑标记、周/月/季度切换 |
| **基金申请生成** | Direction 全景 → Grant Proposal 初稿，含立项依据/技术路线/经费概算，支持 DOCX 导出 |
| **实验计划生成** | D6 缺口识别 → 实验清单（目标/方法/预期/资源/时间） |
| **NL 资产解析** | 自由文本实验描述 → 结构化 `ExperimentAsset` |

### 1.6 质量保障

- **反模式检测**：检测范围过大、假设不可证伪、忽略混杂变量、资源低估等科研陷阱
- **Style Calibration**：上传标杆论文 → 评分基线 → 用户方向与标杆自动对比
- **Material Passport**：研究材料版本追踪 + Dashboard 更新提醒 + diff 视图

### 1.7 Writing Blueprint 扩展

- `WritingBlueprint` 新增 Direction 上下文字段
- 蓝图创建自动注入方向分析摘要
- 大纲节点与方向维度关联映射
