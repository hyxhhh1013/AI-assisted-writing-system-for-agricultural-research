## 二、Wave 1 — Paper Passport + Cockpit ✅ MVP

### 2.1 PaperPassport 契约与数据库

- `contracts/paper-passport.ts`：Phase 0-7 状态机、PaperConfig 类型、进度快照接口
- Prisma `Project.paperPassport` JSONB 字段
- `services/paper-passport-service.ts` + PATCH API

数据模型：
```
paperPassport: {
  currentPhase: 0-7,
  phaseStatus: { locked | ready | in_progress | done },
  config: PaperConfigRecord,
  literature / outline / argument / draftProgress / citationAudit / abstract / reviewRound,
  source: { directionSlug, candidateId }
}
```

### 2.2 Phase 0 PaperConfig 持久化

- 工作台配置面板：论文类型、目标期刊、语言、学科领域、字数范围
- 配置保存写入 `passport.config`
- 创建项目可选从 Direction 桥接配置

### 2.3 Project Cockpit 驾驶舱

- **阶段进度条**：8 Phase 状态机可视化，locked/ready/in_progress/done 四态
- **任务卡片**：当前阶段待完成任务，可点击完成/取消
- **人控/Agent 模式切换**：默认人控（Tab + 按钮），可选自主（Agent Tab）
- **Phase Guide 侧边栏**：阶段指南嵌入工作台
- **阶段自动推进**：从项目快照自动计算当前 phase
- **进度快照**：literature/draftProgress/abstract/reviewRound 多维度记录
- **历史兼容**：无 passport 旧项目自动 bootstrap，不阻塞加载

### 2.4 Agent Phase A（只读 SSE 循环）

- `agent-loop.ts` Phase A：只读 Agent，SSE 事件流
- 工具集：search_knowledge_base、read_section、list_references、get_citation_info
- SSE 事件：tool_call → tool_result → agent_thought → done
- 后续 Wave 2 由 LangGraph 替换
