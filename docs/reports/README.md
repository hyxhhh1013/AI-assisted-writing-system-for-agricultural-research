## 每周如何更新？

1. 周日或汇报前：优先**手写/改**对应周的 `.md`；仅当某周尚无文件时，可用 git 生成骨架（**不会覆盖**已有 `## 本周工作` / 详版周报）：

   ```bash
   node scripts/generate-weekly-reports-from-git.mjs
   ```

   周期以本目录文件名为准（周一至周日）；与自然周算法差一天时，以手写文件为准。

2. 在对应周的 `.md` 里补全「问题 / 计划 / 一句话」；重要周可仿 `周报-2026-06-02至06-06.md` 写详版并导出 PDF：

   ```bash
   # 批量：所有 周报-*.md → .html + .pdf
   node scripts/weekly-md-to-pdf.mjs

   # 单份
   node scripts/export-html-to-pdf.mjs docs/reports/周报-xxxx.html
   ```

3. 工程 PR 完成后在 `ENGINEERING_OPTIMIZATION_QUEUE.md` §4 **补一行会话日志**（团队接力用）。
