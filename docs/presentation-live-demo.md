# 演示 Live Demo 彩排清单

> 配合 `/presentation` 中 `live-demo-bridge` 幻灯片使用。动画备份：`/presentation?backup=1`（含管道动画页）。

## 流程（3～5 分钟）

1. 停在 **live-demo-bridge** 页，口头说明「接下来是真系统」
2. 新开 Tab：`/workbench`（预置 demo 项目，references 已配好）
3. 写作面板 → 选 **Results** → 点「扩写选定章节」
4. 指 SSE：Writer 流式 → Verifier 核查 → Refiner 修正
5. 指引用列表 / citation warnings：每条来自知识库 `[1]…[N]`
6. （可选）切 `/knowledge` 搜刚引用的论文标题
7. 回到 `/presentation`，按 → 继续 **real-case**
