## 三、两项核心任务

### 任务一：文献收集（每方向 1000 篇）

每个方向需收集 **1000 篇** 方向相关的学术文献（期刊论文、会议论文、学位论文等），具体要求：

1. **来源**：优先知网、Web of Science、Scopus、Google Scholar
2. **分类**：按子主题分类整理（如菜心方向可分为：外骨骼设计、机器视觉、末端执行器、田间应用等）
3. **格式**：统一导入知识库系统，支持 PDF 全文 + 元数据
4. **时间**：建议近 5-10 年文献为主，经典文献不限年限
5. **责任人**：各方向负责人统筹，团队成员分工检索

**目标截止日期：____月____日**

### 任务二：论文撰写（每方向 1 篇）

基于已收集的文献和实验室现有数据，每个方向完成 **1 篇学术论文**，具体要求：

1. **工具**：使用「禾书耕文」AI 论文助手系统辅助撰写
2. **流程**：文献导入 → 大纲生成 → AI 扩写 → 人工审校 → 查重降重 → 定稿
3. **质量**：符合 SCI / 中文核心期刊投稿标准
4. **数据**：各方向提供已有的实验数据、调研数据作为论文支撑
5. **责任人**：各方向负责人主导撰写，团队成员提供数据和文献支持

**目标截止日期：____月____日**
