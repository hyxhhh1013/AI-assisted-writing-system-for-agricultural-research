## 开场（2 分钟）：一个真实的故事

> "去年我帮实验室整理文献，167 篇 PDF，每篇要读摘要、标关键词、分类。我花了整整一周。后来我试了 ChatGPT，让它帮我写文献综述——它很流畅地给我列了 10 条参考文献，每一条看起来都像真的，格式完美，DOI 齐全。我去查了，**8 条是编的**。"

> "这就是我做这个项目的起点：**AI 能写，但不能信**。问题不是 AI 能不能帮你写论文，而是你怎么让它写出来的东西**每一条引用都有据可查、每一个数据都能追溯到原文**。"

### 三个核心问题

| 问题 | 现状 | 后果 |
|------|------|------|
| **引用虚构** | ChatGPT/DeepSeek 会编造不存在的论文 | 学术不端风险，审稿人一查就穿帮 |
| **不懂领域** | 通用 AI 不了解农业科研的写作规范 | 田间试验写成实验室实验、品种名乱翻译 |
| **机械劳动** | 排版、引用格式化、跨章节核对 | 60% 的时间花在"怎么写"而非"写什么" |

> "我的目标不是做一个'论文生成器'。我要做的是一套**农业科研写作工作流**——让 AI 处理机械劳动，研究者专注于科学判断。"

## 第二部分：现场演示（8-10 分钟）

### 演示 1：知识库 — 解决"引用虚构"（2 分钟）

**演示要点**：

1. 打开知识库，展示已索引的 910 篇文献、7 个分类
2. 随机打开一篇 PDF → 右侧 AI 对话
   - "这篇的核心发现是什么？"
   - "用了什么表征方法？"
   - AI 的回答**标注了具体页码和段落**——不是凭记忆编的，是读了原文

> "这就是 RAG 的价值。AI 的每句话都有出处，你随时可以追溯到原文验证。"

3. 展示文献入库流程：上传 PDF → 自动解析 → 分类 → 索引

> "整个知识库是实验室自己的文献积累。910 篇论文，12000+ 个知识块，混合检索——关键词精确匹配 + 语义理解，RRF 融合排序。"

### 演示 2：创建项目 + 大纲生成（1 分钟）

1. 新建论文项目：输入题目 + 研究方向
2. AI 自动判断论文类型（发现型/方法型/田间试验型/综述型）
3. 生成结构化大纲，每个子标题含 1-3 句要点

> "不同类型论文有不同的叙事逻辑。田间试验型强调'处理→重复→统计'，综述型强调'进展→分类→展望'。不是一套模板打天下。"

### 演示 3：扩写 + 多 Agent 审查（3 分钟）——核心演示

**这是整个系统最关键的部分。**

1. 选择"结果与讨论"章节 → 点击扩写
2. **实时流式生成**，逐字显示
3. 生成完成后，自动触发 **Verifier 审查**：
   - 展示审查报告：逐条核查每个引用是否存在于知识库中
   - 如果发现问题（引用归属错误、数据不一致），标记出来
4. **自动触发 Refiner 修正**：根据审查意见逐条修正

> "这不是一个人说了算。Writer 写初稿，Verifier 用独立模型审查，Refiner 修正。三步管道，降低幻觉率。"

5. 展示引用编号：`[1] [2] [3]`……每一条都能在参考文献列表中找到对应的真实论文

### 演示 4：图表工具（1 分钟）

1. 快速展示 XRD 峰拟合（输入数据 → 自动分解重叠峰）
2. 展示通用图表（分组柱状图/折线图）
3. 展示一键插入论文正文

> "14 种图表类型，4 大类：科学图表、XRD 分析、示意图、分子结构。加新图只需写一个 Python 脚本 + 一条 JSON 配置，前端自动识别。"

### 演示 5：导出（1 分钟）

1. 点击导出 → 选择模板（SCI / GB/T 7713 / Nature / IEEE）
2. 展示导出的 PDF：
   - 参考文献格式正确（GB/T 7714-2015 标准）
   - 数学公式正确渲染（KaTeX）
   - 图表位置正确

> "一键导出，自动排版。参考文献按首次出现顺序自动编号，格式符合投稿要求。"

## 第三部分：技术深度（3 分钟）

### 3.1 为什么用三个 Agent 而不是一个？

> "自己写、自己审、自己改——你会发现问题吗？"

| 角色 | 模型 | 职责 | 为什么选这个模型 |
|------|------|------|----------------|
| **Writer** | DeepSeek | 基于文献起草初稿 | 写作能力强、成本低 |
| **Verifier** | 智谱 GLM-4 | 独立审查引用和事实 | **不同模型**，避免"自己审自己" |
| **Refiner** | DeepSeek | 逐条修正审查意见 | 被禁止"删引用逃避审查" |

**学术依据**：

- [Chain-of-Verification Reduces Hallucination (Dhuliawala et al., 2024)](https://arxiv.org/abs/2309.11495)
- [Multiagent Debate Improves Factuality (Du et al., 2023)](https://arxiv.org/abs/2305.14325)

### 3.2 RAG 检索策略

```
用户查询 → 研究方向关键词注入
         ↓
    ┌────────────┐    ┌────────────┐
    │ BM25 关键词 │    │ 向量语义    │
    │ 精确匹配    │    │ 意图理解    │
    └─────┬──────┘    └─────┬──────┘
          └───────┬─────────┘
                  ↓
            RRF 倒数秩融合
                  ↓
            来源去重（每篇最多 4 个片段）
                  ↓
            最相关的 20 个文献片段
```

> "BM25 擅长精确匹配专业术语，向量检索擅长理解'用词不同但意思一样'的查询。两种信号融合，比单一方法更准。"

### 3.3 Prompt 设计的学术依据

> "不是随便写个'请帮我写论文'。每条规则都是查了学术写作规范后写进去的。"

- **IMRAD 五步推进**：引言从"重要性→已知→缺口→目标→价值"
- **证据强度分级**：禁止"首次/证明/最优"，用"表明/提示/与…一致"
- **Results/Discussion 铁律**：Results 只报告观察（过去时），Discussion 才解释机制（推测句式）
- **认知负载优化**：基于 [Lost in the Middle (Liu et al., 2023)](https://arxiv.org/abs/2307.03172)，将核心要求放在首尾

## Q&A 预案

**Q: 这和直接问 ChatGPT 有什么区别？**

> "五层差异：① 知识库检索（900+ 篇真实文献，不是凭空编）；② 学术 prompt（IMRAD、证据强度、Overclaim 检测）；③ 多 Agent 审查（Writer 写→Verifier 审→Refiner 改）；④ 质量保障（引用核查、一致性检查）；⑤ 格式导出（PDF/Word，含公式渲染）。ChatGPT 是对话模型，我做的是工作流。"

**Q: AI 写的内容能直接投稿吗？**

> "不能，也不应该。这是辅助工具，帮你减少机械劳动。核心的科学判断、实验设计、数据解读，必须你自己把关。它加速的是'怎么写'，不是'写什么'。"

**Q: 引用真的不会编造吗？**

> "三层防护：Writer 只能引用知识库中真实存在的文献 → Verifier 拿到原文逐条比对 → Refiner 被禁止'删引用逃避审查'。如果检测到疑似虚构，会标记并提醒你人工核实。"

**Q: 支持英文论文吗？**

> "支持。可以切换输出语言（中文/英文），也可以切换排版模板（SCI / Nature / IEEE / GB/T 7713）。"

**Q: 多研究方向混合会影响准确性吗？**

> "检索时会注入你的研究方向关键词（如'生物质热解 碳材料'），确保优先匹配相关文献，不会被其他方向干扰。"
