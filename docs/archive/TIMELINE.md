# 项目落地时间线计划 (6周计划)

## 第一阶段：MVP 核心验证 (Week 1-2)
*   **目标**：跑通“文献检索 + 数据输入 -> 专业生成”的闭环。
*   **任务**：
    *   W1: Dify 平台环境搭建，上传首批 100 篇文献，调试 RAG 检索参数。
    *   W2: 编写“摘要/前言”核心 Prompt，完成极简 Next.js 提交页面。
*   **交付**：内部 Demo，由业务专家验证生成质量。

## 第二阶段：全功能平台化 (Week 3-4)
*   **目标**：上线结构化写作工具集。
*   **任务**：
    *   W3: 实现大纲生成、方法描述、讨论建议等 4-6 个具体工具卡片。
    *   W4: 优化 UI 交互，增加文件上传解析（Excel/CSV）支持，完善 Loading 与错误处理。
*   **交付**：V1.0 内部测试版。

## 第三阶段：调优与正式发布 (Week 5-6)
*   **目标**：提升稳定性，正式交付。
*   **任务**：
    *   W5: 根据内测反馈，精修 Prompt（针对农学语气），修复长文本生成的截断问题。
    *   W6: 部署至实验室正式服务器，编写使用手册，进行全员培训。
*   **交付**：稳定版系统 + 完整文档。
